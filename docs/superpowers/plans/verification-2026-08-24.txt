*** THE MEASUREMENT MUST PROVE ITS OWN PRECONDITION ***

The first version of this section claimed 44/44 PASS and was WRONG. It was
measured against `python3 -m http.server --directory _site`, and the built HTML
hardcodes the absolute production URL on every asset (site.url is set, so
base_path resolves to https://prathmeshrmadhu.github.io). Serving _site directly
loads NO stylesheet — the browser fetches CSS from the live site, which was
unreachable. Every element therefore sat at its UA default, nothing could
overflow, and all 44 results were meaningless. The tell was
getComputedStyle(body).backgroundColor === 'rgba(0, 0, 0, 0)' and
.nav__list display:'block'.

The re-run serves /tmp/site-local — a copy of _site with the absolute site URL
stripped so all URLs are root-relative (launch.json config "local", port 4002) —
and every single measurement asserts
getComputedStyle(body).backgroundColor === 'rgb(8, 48, 42)'
before its scrollWidth is recorded. A frame that fails the assertion is
reported as UNSTYLED, not as a pass. Zero frames were UNSTYLED.

Not `jekyll serve`, in either run. See the note in .claude/launch.json: jekyll's
watcher regenerates _site without reloading _config.yml, which twice silently
rebuilt pages using a stale config and reintroduced the analytics snippet.

Batching note: the preview eval tool times out at 30s and each page costs ~4.5s,
so this runs one page per call. Leftover iframes from a timed-out call slow the
renderer until removed.
